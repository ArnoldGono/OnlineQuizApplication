# Online Quiz Application

Mini project — Object-Oriented Programming using Java  
**Submitted by:** Arnold Nyasha Gono  
**University:** Manav Rachna International Institute of Research and Studies (MRIIRS)

A GUI-based multiple-choice quiz application built with Java Swing (`javax.swing`) and AWT (`java.awt`). Users answer 5 Core Java questions one at a time, receive an answer-selection check, view their final score and percentage in a pop-up dialog, and can restart the quiz.

Uses only the Java standard library (no external JARs or build tools required) and works on Java 8 or newer.

## How to Run

### Using Command Prompt / Terminal
Open a terminal inside your `OnlineQuizApplication` folder and run:

```bash
javac OnlineQuizApplication.java
java OnlineQuizApplication
